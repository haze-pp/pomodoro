# Focus Timer (뽀모도로)

다이얼을 돌려서 쓰는 개인용 집중 타이머예요. 안드로이드 크롬에서 홈 화면에 설치해 앱처럼 쓰는 PWA입니다.

## 사용법

- **다이얼 돌리기**: 시계판을 손가락으로 돌리면 1분 단위로 시간이 맞춰져요(0~60분, 돌릴 때 딸깍 소리). 돌리는 동안 시계 아래에 맞추고 있는 시간이 크게 보여요.
- **START / RESUME (위쪽 버튼)**: START를 누르면 버튼이 눌려 들어간 채로 타이머가 돌아가요. 눌려 있는 버튼을 한 번 더 누르면 버튼이 올라오며 일시정지되고(`PAUSED` 표시), RESUME을 누르면 이어서 시작해요.
- **RESET**: 진행 중(일시정지 포함)에는 실수로 바뀌지 않게 다이얼이 잠기고, 위쪽 버튼 옆에 나타나는 RESET을 약 1초 길게 누르면 처음 맞춘 시간으로 되돌려요(짧게 누르면 무시돼요). RESET하면 하던 집중 시간은 기록되지 않아요(누를 때 안내가 나와요).
- **시작하면**: 아래 버튼 줄이 빠지고 시계가 가운데로 이동해요. 타이머가 끝나거나 RESET을 누르면 버튼이 돌아와요.
- **째깍 표시**: 타이머가 도는 동안 남은 초를 따라 눈금 하나가 한 칸씩 움직여요(소리 없음).
- **이름**: 시계 위의 `+ 이름`을 눌러 지금 타이머에 이름을 붙일 수 있어요(선택). 이름은 기록에 함께 남아요.
- **초기화(아래 줄 맨 왼쪽)**: 프리셋 선택과 이름을 지우고 다이얼을 0으로 돌려요.
- **아래 버튼 4개(세션 프리셋)**: 기본으로 `30분`이 들어 있어요. `+`를 눌러 이름(선택), 집중 시간, 방식, 반복 횟수를 저장하고, 저장된 버튼을 누르면 다이얼과 이름이 그 프리셋으로 맞춰져요. 길게 누르면 수정하거나 삭제할 수 있어요.
  - **집중만**(버튼에 `×4`): 한 회가 끝나면 다음 회 시간이 채워지고 START를 눌러 직접 시작해요.
  - **집중 + 휴식**(버튼에 `↻4`): 집중 → 휴식 → 집중…을 짧은 알람(최대 3초)과 함께 자동으로 이어 가고, 마지막 집중이 끝나면 멈춰요. 휴식 중에는 원판이 옅어지고 `휴식 · 4:59`처럼 보여요.
  - 반복이 2회 이상이면 시계 위에 회차 동그라미가 생기고 마친 만큼 채워져요.
  - 프리셋 없이 다이얼만 돌리면 한 번만 쓰는 타이머가 돼요.
- **기록(왼쪽으로 밀기)**: 화면을 옆으로 밀거나 아래 점을 누르면 기록 화면이 나와요. 끝까지 마친 집중만 기록돼요(휴식·RESET 제외).
  - 오늘, 최근 7일 집중 시간과 연속 일수
  - 최근 18주 잔디: 하루 집중 시간에 따라 진해져요(30분 미만 / 1시간 미만 / 2시간 미만 / 2시간 이상). 칸을 누르면 그날 각 세션을 언제 시작해서 언제 끝냈는지 보여요.
- **사용 방법(오른쪽 위 ?)**: 앱 안에서 사용법을 볼 수 있어요.
- **설정(오른쪽 위)**:
  - 컬러: 기본 테마 세이지, 라벤더, 차콜. `+ 새 테마`로 원하는 만큼 직접 만들 수 있어요(이름·가운데 문구 지정, 다른 테마 값 가져오기, 색상 선택기, 여러 부분 동시 적용. 문구를 비우면 문구 없는 테마). 만든 테마를 고르면 '컬러' 제목 줄 오른쪽에 연필(수정)·휴지통(삭제) 아이콘이 나와요. 길게 눌러도 수정할 수 있어요.
  - 가운데 문구: 기본 테마는 정해진 문구를 쓰고, 직접 만든 테마는 테마 편집 창에서 정해요(비우면 문구 없음).
  - 타이머가 끝나면: 알람이 울리는 시간(1~60초 슬라이더), 알람 소리 켬/끔, 진동, 화면 깜빡임
  - 기타: 다이얼·버튼 딸깍 소리, 남은 시간 숫자 표시, 화면이 꺼졌을 때 알림
  - 기록: 내보내기(JSON 파일)·가져오기(지금 기록에 합침). 기록은 기기에만 저장되니 가끔 백업해 두세요.

알람이 울릴 때 화면을 아무 곳이나 누르면 꺼져요. 타이머가 도는 동안에는 화면이 자동으로 꺼지지 않아요.

## 폰에 설치하기

1. 이 저장소에서 GitHub Pages를 켜요(Settings → Pages → 배포할 브랜치 선택).
2. 안드로이드 크롬으로 `https://<아이디>.github.io/pomodoro/`에 접속해요.
3. 메뉴(⋮)에서 **홈 화면에 추가** 또는 **앱 설치**를 눌러요.

한 번 열고 나면 오프라인에서도 실행돼요.

## 로컬에서 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 알려진 한계

- 웹앱 특성상 전원 버튼으로 화면을 끄거나 다른 앱으로 전환하면 알람이 늦게 울리거나 소리가 안 날 수 있어요. "화면이 꺼졌을 때 알림"을 켜면 알림이 오지만, 이것도 최대 1분 정도 늦을 수 있어요.
- 이 문제를 확실히 해결하려면 아래 APK 전환이 필요해요.

## APK로 전환하기 (나중에)

이 앱은 일반 HTML/JS라서 코드를 그대로 두고 감쌀 수 있어요.

- **PWABuilder / Bubblewrap (TWA)**: 배포된 URL만 있으면 APK/AAB를 만들어 줘요. 가장 간단해요.
- **Capacitor**: 네이티브 플러그인(예약 알림, 백그라운드 알람)을 쓸 수 있어서, 화면이 꺼져도 정확하게 울리게 하려면 이쪽이 좋아요.

## 추후 추가할 기능

- **타이머 동안 방해금지 모드**: 웹앱(PWA)은 안드로이드 방해금지 모드를 켤 권한이 없어요. APK로 전환한 뒤 '방해 금지 접근 권한'을 받으면 START 때 켜고, 끝나면 원래대로 돌려놓을 수 있어요.
- **프리셋 더 많이**: 지금은 4개까지. 필요해지면 목록에서 고르는 방식으로 늘릴 예정이에요.
