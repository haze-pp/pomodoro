# Focus Timer (뽀모도로)

다이얼을 돌려서 쓰는 개인용 집중 타이머예요. 안드로이드 크롬에서 홈 화면에 설치해 앱처럼 쓰는 PWA입니다.

## 사용법

- **다이얼 돌리기**: 시계판을 손가락으로 돌리면 1분 단위로 시간이 맞춰져요(0~60분, 돌릴 때 딸깍 소리). 돌리는 동안 시계 아래에 맞추고 있는 시간이 크게 보여요.
- **START / PAUSE / RESUME (위쪽 버튼)**: START로 시작하고, 진행 중엔 PAUSE로 일시정지, 일시정지 중엔 RESUME으로 이어서 해요. 일시정지 중에는 시계 아래에 `PAUSED`가 표시돼요.
- **RESET**: 진행 중(일시정지 포함)에는 실수로 바뀌지 않게 다이얼이 잠기고, 위쪽 버튼 옆에 나타나는 RESET으로 처음 맞춘 시간으로 되돌려요.
- **시작하면**: 자주 쓰는 시간 버튼이 옆으로 빠지고 시계가 가운데로 이동해요. 타이머가 끝나거나 RESET을 누르면 버튼이 돌아와요.
- **째깍 표시**: 타이머가 도는 동안 남은 초를 따라 눈금 하나가 한 칸씩 움직여요(소리 없음).
- **오른쪽 버튼 4개(자주 쓰는 시간)**: 기본으로 `30분`이 들어 있어요. `+`를 눌러 시간을 저장하고, 저장된 버튼(예: `30분`)을 누르면 다이얼이 그 시간으로 맞춰져요. 길게 누르면 수정하거나 삭제할 수 있어요.
- **사용 방법(오른쪽 위 ?)**: 앱 안에서 사용법을 볼 수 있어요.
- **설정(오른쪽 위)**:
  - 컬러: 세이지, 라벤더, 차콜, 나만의(색상을 직접 지정)
  - 가운데 문구: 원하는 문구로 바꾸기(모든 테마에 공통 적용, 비우면 문구 없음)
  - 타이머가 끝나면: 알람이 울리는 시간(1~60초 슬라이더), 알람 소리 켬/끔, 진동, 화면 깜빡임
  - 기타: 다이얼 돌릴 때 소리, 남은 시간 숫자 표시, 화면이 꺼졌을 때 알림

알람이 울릴 때 화면을 아무 곳이나 누르면 꺼져요. 타이머가 도는 동안에는 화면이 자동으로 꺼지지 않아요.

## 폰에 설치하기

1. 이 저장소에서 GitHub Pages를 켜요(Settings → Pages → 배포할 브랜치 선택).
2. 안드로이드 크롬으로 `https://<아이디>.github.io/pomodoro/`에 접속해요.
3. 메뉴(⋮)에서 **홈 화면에 추가** 또는 **앱 설치**를 눌러요.

한 번 열고 나면 오프라인에서도 실행돼요.

## 로컬에서 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 알려진 한계

- 웹앱 특성상 전원 버튼으로 화면을 끄거나 다른 앱으로 전환하면 알람이 늦게 울리거나 소리가 안 날 수 있어요. "화면이 꺼졌을 때 알림"을 켜면 알림이 오지만, 이것도 최대 1분 정도 늦을 수 있어요.
- 이 문제를 확실히 해결하려면 아래 APK 전환이 필요해요.

## APK로 전환하기 (나중에)

이 앱은 일반 HTML/JS라서 코드를 그대로 두고 감쌀 수 있어요.

- **PWABuilder / Bubblewrap (TWA)**: 배포된 URL만 있으면 APK/AAB를 만들어 줘요. 가장 간단해요.
- **Capacitor**: 네이티브 플러그인(예약 알림, 백그라운드 알람)을 쓸 수 있어서, 화면이 꺼져도 정확하게 울리게 하려면 이쪽이 좋아요.

## 추후 추가할 기능

- **타이머 동안 방해금지 모드**: 웹앱(PWA)은 안드로이드 방해금지 모드를 켤 권한이 없어요. APK로 전환한 뒤 '방해 금지 접근 권한'을 받으면 START 때 켜고, 끝나면 원래대로 돌려놓을 수 있어요.
- **사이클 모드**: "집중 25분 → 휴식 5분" 또는 "플랭크 1분 → 휴식 1분 × N회"처럼 구간을 이어서 자동으로 반복하는 기능. 구간 목록(이름, 시간, 원판 색)과 반복 횟수를 저장하고, 한 구간이 끝나면 짧은 알람 뒤에 다음 구간 시간으로 다이얼을 다시 채우는 방식으로 구현할 예정이에요.
- **기록**: 완료한 세션(시작 시각, 설정 시간, 끝까지 했는지)을 기기에 저장해 오늘 몇 회, 총 몇 분 집중했는지와 주간 그래프를 보여 주는 기능.
