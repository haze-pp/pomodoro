    기본

    1. 시계판을 손가락으로 돌려 시간을 맞춰요. 1분 단위로 최대 60분까지 맞출 수 있어요.
    2. 위쪽 START를 누르면 버튼이 눌려 들어간 채로 타이머가 돌아가요.
    3. 눌려 있는 버튼을 한 번 더 누르면 버튼이 올라오면서 일시정지돼요. RESUME을 누르면 이어서 시작해요.
    4. 처음 맞춘 시간으로 되돌리려면 위쪽 버튼 옆에 나타나는 RESET을 버튼이 끝까지 들어갈 때까지(약 1초) 길게 눌러요. RESET하면 하던 집중 시간은 기록되지 않아요.
    5. 진행 중(일시정지 포함)에는 실수로 눌리지 않게 위쪽 버튼(START/PAUSE/RESUME, RESET) 말고는 모두 잠겨요. 다이얼, 이름, 설정, 사용 방법, 기록 화면으로 넘기기도 막혀요. 알람이 울릴 때 화면을 눌러 끄는 건 돼요.
    6. 시간이 다 되면 알람이 울려요. 화면 아무 곳이나 누르면 꺼져요.

    이름

    • 시계 위의 + 이름을 눌러 지금 타이머에 이름을 붙일 수 있어요. 안 붙여도 괜찮아요.
    • 이름은 기록에 함께 남아요.

    세션 프리셋

    • 시계 아래 +를 눌러 이름(선택), 집중 시간, 방식, 반복 횟수를 저장해요. 길게 누르면 수정하거나 삭제할 수 있어요.
    • 맨 왼쪽 초기화를 누르면 프리셋 선택과 이름이 지워지고 다이얼이 0으로 돌아가요.
    • 집중만: 한 회가 끝나면 다음 회 시간이 채워지고, START를 눌러 직접 시작해요. 버튼에 ×4처럼 보여요.
    • 집중 + 휴식: 집중 → 휴식 → 집중…이 짧은 알람과 함께 자동으로 이어져요. 마지막 집중이 끝나면 멈춰요. 버튼에 ↻4처럼 보여요.
    • 반복이 2회 이상이면 시계 위에 동그라미가 생기고, 마친 회차만큼 채워져요.
    • 프리셋 없이 다이얼만 돌리면 한 번만 쓰는 타이머가 돼요.

    기록

    • 화면을 왼쪽으로 밀면(또는 아래 점을 누르면) 기록 화면이 나와요.
    • 끝까지 마친 집중 시간만 기록돼요. 휴식 시간과 RESET으로 멈춘 시간은 기록되지 않아요.
    • 칸이 진할수록 그날 오래 집중한 거예요. 칸을 누르면 그날 언제 시작해서 언제 끝냈는지 볼 수 있어요.
    • 기록은 이 기기에만 저장돼요. 설정에서 내보내기로 백업해 두세요.

    설정

    • 컬러 테마를 고를 수 있어요.
    • + 새 테마로 색과 가운데 문구를 정해 나만의 테마를 여러 개 만들 수 있어요. 다른 테마 값을 가져와 시작할 수도 있고, 문구를 비우면 문구 없는 테마가 돼요. 만든 테마를 고르면 '컬러' 오른쪽에 나오는 연필·휴지통 아이콘으로 수정하거나 삭제해요.
    • 알람이 울리는 시간, 소리, 진동, 화면 깜빡임을 정할 수 있어요.

    알아 두면 좋아요

    • 타이머가 도는 동안에는 화면이 꺼지지 않아요.
    • 다른 앱으로 가거나 화면을 끄면 알람이 늦게 울릴 수 있어요. 설정에서 화면이 꺼졌을 때 알림 보내기를 켜 두면 알림으로 알려 줘요.
